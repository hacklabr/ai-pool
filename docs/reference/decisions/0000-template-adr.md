# ADR-0000 — Template de ADR

> Este arquivo é o formato de referência para todos os ADRs deste projeto.
> Numeração sequencial de 4 dígitos: o próximo ADR é o máximo existente + 1.
> ADRs aceitos são **imutáveis**: uma decisão nova cria um ADR NOVO que
> referencia o substituído (Status: `substituído por ADR-NNNN`). Nunca
> renumere ou altere ADRs existentes.

**Status:** proposto | aceito | substituído por ADR-NNNN

**Contexto:** qual força/problema motiva a decisão; alternativas consideradas.

**Decisão:** o que foi decidido, em uma voz ativa ("Vamos...").

**Consequências:** positivas, negativas e o que fica mais fácil/difícil.

**Evidências:** paths do código/manifestos onde a decisão se materializa.
